# GenSports

Landing page responsive para **GenSports**, una tienda deportiva tipo outlet con ropa, calzado y accesorios de grandes marcas a precios especiales.

## Descripción

GenSports es una propuesta de tienda en línea pensada para quienes buscan equiparse para su deporte sin pagar de más. La página incluye un catálogo filtrable por disciplina, un carrito de compras funcional, una oferta con cuenta regresiva y un sorteo de boletos para la NFL en CDMX.

Este proyecto fue desarrollado de manera colaborativa durante un hackatón.

## Características

- **Sorteo inicial:** ventana emergente con el sorteo de boletos y acceso directo al formulario de registro.
- **Oferta flash:** barra fija con cuenta regresiva que se reduce de tamaño al hacer scroll.
- **Hero con carrusel:** categorías deportivas destacadas con cambio automático y controles manuales.
- **Categorías deportivas:** Running, Fútbol, Básquetbol y Americano. Al elegir una, se filtra el catálogo.
- **Catálogo de productos:** más de 25 productos con filtros por deporte y vista de detalle.
- **Carrito de compras:** agregar productos, cambiar cantidades, eliminar y ver el total.
- **Beneficios y marcas:** tarjetas de beneficios y carrusel animado de marcas participantes.
- **Formulario de suscripción:** registro para participar en el sorteo.
- **Diseño responsive:** adaptado a computadora, tableta y celular, con menú desplegable en pantallas pequeñas.
- **Accesibilidad:** navegación con teclado, etiquetas ARIA y respeto a la preferencia de movimiento reducido.

## Cómo ejecutarlo

1. Clona el repositorio:

   ```bash
   git clone https://github.com/tu-usuario/gensports.git
   ```

2. Abre la carpeta del proyecto.
3. Abre `index.html` en tu navegador, o usa la extensión **Live Server** de Visual Studio Code para verlo con recarga automática.

No requiere instalación de dependencias ni proceso de compilación.
